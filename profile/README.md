## 关于我们

厦门大学 RCS 机器人队成立于 **2008 年 11 月**，是一支汇聚不同院系、不同专业同学的学生科技创新与工程实践团队。因为对机器人的热爱，我们走到一起，在设计、制造、编程与调试中探索技术，在一次次协作中把想法变成能够运行的机器人。

从 ROBOCON、RoboMaster 到 RoboCup，RCS 在不同的机器人竞赛中积累经验、传承技术。我们珍视赛场上的每一次突破，也珍视实验室里每一个被认真解决的问题。

## 技术方向

机器人是一项需要共同完成的系统工程。机械、硬件、电控与视觉相互配合，让结构、电路、控制与感知成为一个整体。

| 技术组 | 标识 | 主要方向 |
| :--- | :--- | :--- |
| 电控组 | `embedded` | 嵌入式开发、电机驱动与运动控制、通信协议、系统联调 |
| 视觉组 | `vision` | 目标检测与跟踪、位姿估计、视觉算法、感知与决策 |
| 机械组 | `mechanical` | 机构设计、传动与结构优化、加工装配、整机集成 |
| 硬件组 | `hardware` | 电路与 PCB 设计、供电与接口设计、板级调试与验证 |

## 在这里，积累与传承

我们希望把这个 GitHub 组织建设成战队共同维护的技术档案，让每一届队员的探索，都成为下一届继续前进的基础。

- **项目与代码**：记录开发过程，保留版本演进，让改进有迹可循。
- **设计与文档**：整理机械与硬件设计、接口约定、环境配置和使用说明。
- **调试与复盘**：留下问题现象、分析过程和验证结果，帮助后来者理解设计背后的选择。
- **培训与交接**：积累入门材料和实践经验，让知识在队员之间持续传递。

## 交流与共创

欢迎热爱机器人的同学与我们交流，也欢迎与其他高校战队分享工程实践经验。对于公开项目，欢迎通过对应仓库的 Issues 提出问题与建议，或通过 Pull Request 参与改进。

我们相信，一次清晰的记录、一场充分的讨论、一个经过验证的改动，都能让团队向前走一步。
